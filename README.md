# Hi, I'm Jether Bagor 👋

### Assistant Software Engineer | Software Developer & QA Tester

**I build software around real problems, not just features.**

I'm interested in helping businesses move beyond manual processes by turning operational challenges into practical digital solutions.

My work combines software development and quality assurance. From building applications to testing how they behave in real-world scenarios, I approach software with two questions: **Does it solve the problem? And does it work the way people need it to?**

## 💼 What I Do

- **Software Development** — Build web applications that organize information, simplify workflows, and address practical problems.
- **Software Quality Assurance** — Test application functionality across different user roles, identify defects, document findings, and verify fixes.
- **Problem Solving** — Understand how a process works, identify where it fails, and explore how software can improve it.
- **Continuous Improvement** — Debug issues, optimize existing features, and apply testing findings to improve software reliability.
